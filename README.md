# Refinance-Propensity-Model
A data-driven model that predicts mortgage refinance likelihood and optimizes outreach targeting. 

## Problem Statement
A mortgage lender wants to identify which borrowers are most likely to refinance and should be targeted for outreach. 

## Approach
- Expected profit strategy outperformed savings heuristic by 40%
- Model achieved strong AUC on test set
- Business impact: more efficient marketing spend, higher conversion rates

## Tech Stack
- Python, Pandas, NumPy, Scikit-learn
- Logistic Regression, StandardScaler

## How to Run
1. Clone the repo
2. Run 'python refinance_model.py'
3. Outputs: portfolio data, model performance, strategy comparison
